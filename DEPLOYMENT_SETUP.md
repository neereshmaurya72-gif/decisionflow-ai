# DecisionFlow AI Deployment Setup

DecisionFlow AI currently uses a built-in rule-based and heuristic extraction engine.

No IBM watsonx.ai credentials, API keys, cloud AI services, email APIs, or external provider configuration are required.

## Required environment variable

- `FLASK_SECRET_KEY` — use a private random value in production.

## Deploy

Push the project to GitHub and deploy it on Render using the existing build and start configuration.
